# E-Commerce-Sales-Analysis-SQL-Project

I recently completed an E-Commerce Sales Analysis project using SQL and MySQL, where I explored how data can help businesses make smarter decisions.

Instead of just writing queries, I focused on answering real business questions such as:
📊 What is the total revenue generated?
📦 Which products bring the highest revenue?
🌍 Which cities drive the most sales?
📈 How do sales change month-to-month?
❌ Why are some orders getting cancelled?

Using SQL joins, aggregations, and analytical queries, I analyzed multiple tables like customers, orders, products, and order_items to uncover meaningful insights.

🔎 Some Key Insights
• A small number of products contribute to a large portion of revenue.
• Sales are concentrated in a few top cities.
• Monthly trends reveal seasonal demand patterns.
• Around 37% of orders were cancelled, indicating potential operational issues.
• Some registered customers never placed an order — a great opportunity for targeted marketing.

💡 What I Learned
This project helped me strengthen my understanding of:
• SQL Joins
• Aggregations & Grouping
• Business-driven data analysis
• Turning raw data into actionable insights

📌 Tools Used: MySQL | SQL | Business Analytics

This experience reinforced an important lesson:
Data is valuable only when we turn it into decisions.
