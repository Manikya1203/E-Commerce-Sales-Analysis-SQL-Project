🛒 E-Commerce Sales Analysis (SQL Project)
📌 Project Overview
This project analyzes an E-Commerce sales dataset using SQL and MySQL to uncover business insights that help companies make data-driven decisions.
Instead of only writing queries, this project focuses on solving real business problems such as identifying revenue drivers, customer behavior, and sales trends.

🎯 Business Questions
This project answers important business questions like:
💰 What is the total revenue generated?
📦 Which products generate the highest revenue?
🌍 Which cities drive the most sales?
📈 How do sales change month-to-month?
❌ Why are some orders getting cancelled?

🗂️ Dataset
The project uses a relational database containing the following tables:
customers – Customer information
orders – Order details
products – Product catalog
order_items – Items included in each order

🗃️ Database Schema
The database structure connects customers, orders, products, and order items to allow complete sales analysis.
Tables relationships:
Customers → Orders → Order_Items → Products

🔍 Key Insights
After analyzing the dataset, several important insights were discovered:
📊 A small number of products contribute to a large portion of revenue
🌍 Sales are concentrated in a few top cities
📅 Monthly trends reveal seasonal demand patterns
❌ Around 37% of orders were cancelled, indicating possible operational issues
👤 Some registered customers never placed an order, showing a marketing opportunity

🧠 SQL Concepts Used

This project demonstrates several important SQL concepts:
SQL Joins
Aggregations (SUM, AVG, COUNT)
GROUP BY
Filtering with WHERE
Date Functions

Business-focused analysis queries
